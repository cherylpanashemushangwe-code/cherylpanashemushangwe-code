## Featured projects

**[Loan Default Prediction](https://github.com/cherylpanashemushangwe-code/Data-Science-and-Analytics-Projects/tree/main/Loan-Default-Prediction)**
Logistic regression vs SVM on 2,559 loan applicants, with the decision threshold set by the real cost of a missed default compared with a wrong decline. Python, scikit-learn.

**[Hospital Closure Risk Model](https://github.com/cherylpanashemushangwe-code/Data-Science-and-Analytics-Projects/tree/main/Hospital-Closure-Risk-Model)**
Financial distress features from 22,508 Medicare cost reports, plus a simulation of Medicaid revenue cuts that flags high risk hospitals. Python, scikit-learn.

**[Mortgage Fairness Analysis](https://github.com/cherylpanashemushangwe-code/Data-Science-and-Analytics-Projects/tree/main/Mortgage-Fairness)**
100,000 Massachusetts mortgage applications from the CFPB API. A logistic regression controlling for income, loan amount, and DTI tests for gaps in denial rates, and a Power BI dashboard presents the results. Python, statsmodels, Power BI.

**[Customer Churn Prediction](https://github.com/cherylpanashemushangwe-code/Data-Science-and-Analytics-Projects/tree/main/Customer-Churn-Prediction)**
Logistic regression compared with neural networks on 5,000 telecom customers, plus a Power BI dashboard of churn drivers. Python, scikit-learn, Power BI.

**[RetailPulse Ecommerce SQL](https://github.com/cherylpanashemushangwe-code/Data-Science-and-Analytics-Projects/tree/main/RetailPulse-Ecommerce-SQL)**
A 9 table PostgreSQL schema and 20 analysis queries covering RFM segmentation, cohort retention, churn, margins, and carrier performance. PostgreSQL, Power BI.

**[Boston 311 Service Performance](https://github.com/cherylpanashemushangwe-code/Data-Science-and-Analytics-Projects/tree/main/Boston-311-Service-Performance)** (team of 4)
1.2 million city service requests from 2015 to 2019, analyzed with chi square tests, logistic regression, and LASSO to find what drives timely closure. R.
